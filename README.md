# video-slice-contractor

Публичная копия рабочего пространства исполнителя (риггинг/анимация в Blender) для эталонного
среза Phase 0.5 проекта персонализированных детских мультфильмов. Начни с
`contractor/README.md`. Рывок 1 (персонаж) и рывок 2 (анимация трёх шотов,
`contractor/burst-2/TASK.md`, приёмка — `contractor/burst-2/ACCEPTANCE.md`) закрыты, их файлы
оставлены как справка. Вопросы и ответы для обоих рывков — в одном файле
`contractor/burst-1/QUESTIONS.md`; его статус-блок наверху всегда говорит, что делать сейчас.
Работа через fork и Pull Request.

Здесь лежит ровно то, что нужно для задания и самопроверки; основной репозиторий проекта
приватный. Права: см. `NOTICE.md`.
