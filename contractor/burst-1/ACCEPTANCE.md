# Приёмка рывка 1

Сдача — файл `deliverables/character_v<NN>.blend` (текстуры упакованы: File → External Data →
Pack Resources; размер до 90 МБ, иначе напиши в `QUESTIONS.md` — включим LFS) плюс
заполненные `REPORT.md` и `LICENSES.md`. Каждая версия — новый номер, старые не удаляются.

## Проверки, которые ты запускаешь сам перед сдачей

Один раз: Blender 5.2.1 LTS и OpenImageIO по `benchmarks/bakeoff/01J7B000000000000000BAKEXP/slice/REBUILD.md`
(шаги 1–2) и Python-зависимости проверок: `python3 -m pip install -r requirements-dev.txt`
(или venv в `.venv/` — скрипт найдёт его сам). Затем из корня репозитория, с Blender в PATH:

    slice/check_asset.sh deliverables/character_v01.blend /tmp/asset_check

Скрипт прогоняет ровно ту цепочку, которую проходит манекен: проверка структуры сцены →
экспорт шота → проверка экспорта → проверка Alembic → пробный рендер одного кадра и стилла
(64 сэмпла, 25 % — около десяти минут на Apple M4; меньше сэмплов нельзя, гейт компоновки на них не сходится) → сборка бандлов → компоновка → тест обратной проекции (голова,
собранная только из экспортированных данных, ложится на рендер). Последняя строка должна быть
`ASSET_CHECK_OK`. При ошибке скрипт останавливается на шаге и пишет, что не так; полный лог
— `/tmp/asset_check/last_step.log`. Хвост лога вставь в `REPORT.md`.

Что означают типичные ошибки:

| Сообщение | Причина |
|---|---|
| `collection C_… missing`, `bone … missing`, `material … missing` | имена не по контракту |
| `ray visibility is not shadow-caster-only` | у объекта головы/волос не выставлены флаги из TASK §6 |
| `SOCKET_HEAD not bone-parented to the head bone` | сокет не привязан к кости `head` |
| `C_HEAD: exactly one render-visible mesh must carry SOCKET_BOUNDARY` | кольцо не на одном меше-оболочке (нет или несколько) |
| `rest gap … ≥ 0.005` | кольца головы и тела не совпадают в покое |
| `SOCKET_BOUNDARY count mismatch` / `weights are not distinct` | кольца разного размера или веса не заданы порядком |
| `hair Curves with points cannot be re-projected` | волосы не мешем |
| `round-trip FAIL` | голова не садится обратно по экспорту — чаще всего голова не следует за сокетом или лежит внутри тела |

## Что мы проверяем при приёмке

1. `check_asset.sh` проходит у нас на 25 % и на 100 % (пороги пока предварительные; если
   на 100 % что-то падает по порогу, а не по структуре, это наша калибровка, не твоя ошибка —
   мы скажем).
2. Визуально: голова — настоящая голова, шов на шее чистый, кожа открыта на голове, шее,
   кистях; волосы отдельным ассетом; никаких головных уборов и очков.
3. `LICENSES.md` заполнен для каждого стороннего элемента.
4. В файле нет ничего из §7 задания.
5. Сдача пересобирается одной командой из `deliverables/scripts/` и MPFB2 указанного в
   `LICENSES.md` коммита; команда и ожидаемый результат записаны в `REPORT.md`, мы повторяем
   сборку у себя (Q11).

Критерий «сделано»: пункты 1–5 выполнены на одной и той же версии файла.
