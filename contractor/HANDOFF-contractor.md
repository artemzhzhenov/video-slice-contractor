## Как всё устроено

- **Канал** — публичный репозиторий https://github.com/artemzhzhenov/video-slice-contractor. Задания и приёмка —
  `contractor/burst-*/TASK.md`, `ACCEPTANCE.md`, `REPORT.md`; вопросы и ответы — `contractor/burst-1/QUESTIONS.md`
  (Q1–Q53); рывок 3 — `contractor/burst-3/`, спецификация — `docs/experiments/synthetic-reference-set.md`. Пушить из claude.ai я не могу: сдаю архивом, Артём коммитит.
- **Среда в claude.ai обнуляется** — нет ни Blender-бинаря, ни GPU. Восстановление: `tools/restore_env.sh` (~1 мин):
  `bpy==5.2.1` как модуль, скрипты запускаются через `tools/bpy_module_runner.py`. MPFB2 нужен только для
  пересборки персонажа; правки шотов идут скриптом анимации поверх принятого `.blend`.
- **Рывок 3, сборка ребёнка:** `build_character.py --subject subject_NN.json` (классы волос `curly_voluminous`,
  `short_straight`, `long_straight`; `bangs`; `glasses`) → `packet_subject_NN.py --scene window_day` → `truth_subject_NN.py`.
  Скрипты и json — в `scripts/burst3/`, замерные инструменты (зазоры, черты лица, прядь на щеке) — в `tools/burst3/`.
  Нужен `jsonschema` в venv для `check_exports`.
- **Сборка шота:** `build_character.py` на шаблоне шота → `make_shot_00X.py` → `animate_shot_00X.py`.
  Скрипт анимации сам снимает анимацию и ставит ключи заново — поэтому перезапуск на принятом файле даёт
  то же, что полная пересборка (проверено хэшем в Q50).
- **Лимит одной команды — 300 с.** Тяжёлые гейты (`check_hand_pose` 7-й редакции ~10 с/кадр) — порциями
  по 15–30 кадров; ролик 120 кадров при 432 px / 6 сэмплах помещается в одну команду (~180–260 с).

## Правила, которые я усвоил за рывки (не повторять ошибок)

1. **Никаких переключателей по окну.** Кривые — одна на весь шот (Catmull-Rom → выборка по кадрам → сглаживание
   1-2-1), добавки — с нулевой скоростью на краях. Ступеньки по окну давали рывки трижды (голова, наклон, плечо).
2. **Мерить инструментами заказчика** (`check_states`, `check_hand_pose`, `measure_*`), а не своими: мои
   самодельные замеры ошибались (открытая оболочка головы, средняя нормаль замкнутого меша, центроид кисти).
3. **Смотреть лист кадров подряд, без пропусков**, на переходах: гейт ловит положение, но не «указывает
   пальцем», «рука палкой», «кисть растопырена».
4. **Анатомия — жёсткие условия, число — проверка, не цель.** Оптимизатор по одному числу ставил руку сквозь
   голову (Q43).
5. **Отчёт — один набор цифр, измеренных на сдаваемом файле.** Ролик — одним прогоном из сдаваемого файла,
   хэш до и после. Файлы выкладывать карточками **и** архивом.
6. Взгляд целить из точки между глаз; знаки после зеркала камеры проверять по всем ключам.
7. **В замерах по кадрам брать меш через `bpy.data.meshes.new_from_object`,** а не трансформировать `to_mesh()` на
   месте: у статичных объектов он кэшируется, и смещение копится от кадра к кадру (ошибка точки 02–03).
