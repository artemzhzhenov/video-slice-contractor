## Что проверяем мы

| Проверка | Принимается, когда |
|---|---|
| происхождение | файл собран из шаблона только твоими скриптами; скан скриптов чистый; каждый сторонний элемент в `LICENSES.md`; ни одного файла-картинки извне проекта; строка о происхождении в отчёте |
| пересборка | наш пересбор из твоих скриптов совпадает с файлом до 1·10⁻⁶; `build_character.py` по-прежнему собирает v04.1 тем же содержимым |
| тело не тронуто | меш-данные тела, одежды и риг совпадают с v04.1 по хэшам |
| сокет | кольцо головы ребёнка совпадает с кольцом головы по умолчанию до 1·10⁻⁶; ребёнок в `SHOT_001` проходит наш round-trip и критерий шва на 100 % |
| конверт | голова и волосы внутри конверта головы — или в отчёте сказано, где выходят и насколько |
| каналы | на ребёнке двигаются все каналы, которые двигают голову по умолчанию (`channel_reference.py`, наш прогон на GPU) |
| глаза и веки | добавлено 2026-10-25 (Q58): в покое и при каждом крайнем положении век ни одна вершина века не внутри глазного яблока (касание до 0,05 мм); закрытый глаз (моргание, `lid_aperture` −1) не виден спереди и на 35° с боков; закрытое веко лежит на глазу (медиана зазора ≤ 2,8 мм, предварительно) — `slice/measurements/eye_lid_check.py`; крупные планы глаз смотрим глазами |
| рот | добавлено 2026-10-28 (Q65; нижние зубы сквозь уголки рта в смехе `SHOT_001`, верхние — перед губой в профиле `SHOT_002` — у головы по умолчанию и у всех семи детей, при всех зелёных гейтах): ни на одном кадре трёх шотов камера шота не видит ни зубов, ни языка вне губ; инструмент — наш; крупные планы рта (улыбка, открытый рот, смех, профиль `SHOT_002`) смотрим глазами; `slice/measurements/mouth_check.py` → `MOUTH_OK` на всех кадрах трёх шотов; нижние зубы и язык двигаются жёстким телом — отклонение формы ≤ 0,2 мм (владелец, Q66) |
| тон | albedo кожи головы и тела — ровно тон из `subject_01.json` (в материале и на плоско освещённом рендере) |
| волосы | класс виден; волосы висят на сокете жёстко; на любом кадре трёх шотов и в крайних положениях каналов с кожей пересекаются только те грани волос и кожи, что в покое (по набору граней, не по числу пар — решение владельца 2026-10-26; `accessory_clearance.py` → `HAIR_SKIN_FACES_OK`); с бровями, глазами, телом — ни одной |
| черты лица | наши замеры на меше (ширина лица, межглазье, нос) совпадают с `subject_01.json`; отличие от головы по умолчанию заметно |
| «своё семейство» | остаток лучшей подгонки таргетами MPFB — замеряем и записываем (пока не гейт) |
| «фото родителей» | четыре сцены на ребёнка (окно днём, тёплый вечер, свет сверху, открытая тень) рендерятся у нас детерминированно; в `open_shade` на ребёнка не падает прямое солнце — только небо (2026-10-27); цвет одежды у каждого из девяти свой, без повторов (владелец, 2026-10-27); вид фотореалистичный — смотрит владелец |
| эталон | все ракурсы на месте, вид мастера, свет `SHOT_001` |
