## Что проверяем мы

| Проверка | Принимается, когда |
|---|---|
| происхождение | файл собран из шаблона только твоими скриптами; скан скриптов чистый; каждый сторонний элемент в `LICENSES.md`; ни одного файла-картинки извне проекта; строка о происхождении в отчёте |
| пересборка | наш пересбор из твоих скриптов совпадает с файлом до 1·10⁻⁶; `build_character.py` по-прежнему собирает v04.1 тем же содержимым |
| тело не тронуто | меш-данные тела, одежды и риг совпадают с v04.1 по хэшам |
| сокет | кольцо головы ребёнка совпадает с кольцом головы по умолчанию до 1·10⁻⁶; ребёнок в `SHOT_001` проходит наш round-trip и критерий шва на 100 % |
| конверт | голова и волосы внутри конверта головы — или в отчёте сказано, где выходят и насколько |
| каналы | на ребёнке двигаются все каналы, которые двигают голову по умолчанию (`channel_reference.py`, наш прогон на GPU) |
| тон | albedo кожи головы и тела — ровно тон из `subject_01.json` (в материале и на плоско освещённом рендере) |
| волосы | класс «кудрявые объёмные» виден; волосы висят на сокете жёстко |
| черты лица | наши замеры на меше (ширина лица, межглазье, нос) совпадают с `subject_01.json`; отличие от головы по умолчанию заметно |
| «своё семейство» | остаток лучшей подгонки таргетами MPFB — замеряем и записываем (пока не гейт) |
| «фото родителей» | сцена рендерится у нас детерминированно; вид фотореалистичный — смотрит владелец |
| эталон | все ракурсы на месте, вид мастера, свет `SHOT_001` |

Решение по игре и виду — владелец, на наших рендерах. Потом — оценка на остальных восемь детей.
