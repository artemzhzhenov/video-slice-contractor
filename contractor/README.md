# Contractor workspace

Рабочее пространство фрилансера-риггера/аниматора (Blender) для эталонного среза Phase 0.5.

**Где работать.** Публичный репозиторий https://github.com/artemzhzhenov/video-slice-contractor
— это копия только этой папки и инструментов, нужных для самопроверки. Основной репозиторий
проекта приватный; в нём эта же папка живёт в ветке `contractor/burst-1` и синхронизируется
с публичной копией скриптом `scripts/export_contractor_repo.sh` (в приватном).

**Как сдавать.** Сделай fork публичного репозитория, работай в своей копии, открывай Pull
Request в `main` публичного репозитория при каждом заметном шаге (не только в конце): PR — это
и отчёт, и точка обсуждения. Мы отвечаем в PR и в `burst-1/QUESTIONS.md`.

| Файл | Кто пишет | Что это |
|---|---|---|
| `burst-1/TASK.md` | мы | задание: что сделать, точные имена, ограничения, как проверить |
| `burst-1/ACCEPTANCE.md` | мы | приёмка: команда, которая должна пройти, и что считается сдачей |
| `burst-1/REPORT.md` | фрилансер | отчёт о ходе работы, обновляется при каждом PR |
| `burst-1/QUESTIONS.md` | обе стороны | вопросы и ответы, нумерованные, с датами |
| `burst-1/LICENSES.md` | фрилансер | откуда взят каждый сторонний ассет и его лицензия |
| `burst-1/deliverables/` | фрилансер | сами файлы сдачи (`.blend` с упакованными текстурами) |

Правила: маленькие коммиты с понятными сообщениями; никаких фотографий реальных детей и
никакого сходства с реальным человеком нигде в файлах; никаких платных внешних сервисов от
имени проекта; ничего из этого репозитория не переиспользовать вне задания (см. `NOTICE.md`
в публичной копии).

Документы контракта (на английском, они главнее этого текста при расхождении):
`docs/adr/ADR-0002-master-head-interface.md`, `slice/conventions.json`,
`slice/channel_map.json`, `slice/state_map.json`, `slice/README.md`, установка —
`benchmarks/bakeoff/01J7B000000000000000BAKEXP/slice/REBUILD.md`, шаги 1–3.
